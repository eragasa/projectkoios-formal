# Working papers

These directories contain non-authoritative, Formal-owned research manuscripts. Exact propositions and proof terms remain in Lean source, declaration identity and status remain in `docs/theorem-manifest.md`, and statement-level explanations remain in `proofs/`.

## Current papers

- [`gauge-constrained-model-adequacy/`](gauge-constrained-model-adequacy/) — working paper on alignment families, Fourier locality, and exact finite adequacy decisions.

## Requirements

Each paper must:

- identify its immutable Formal source revision;
- preserve declaration IDs, hypotheses, operand conventions, and nonclaims;
- distinguish checked results from proposed theorem work;
- distinguish proof from runtime evidence, applicability, novelty, and publication status;
- cite external sources only after source review;
- disclose absent independent review; and
- compile outside the repository without tracking generated output.

Prospective external manuscripts may receive bounded editorial exports from these papers. They do not control theorem identity or status in this repository.
