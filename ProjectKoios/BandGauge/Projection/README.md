Documentation-only folder reserved for retained low-eigenpair compression, invariant-subspace reconstruction, explicit residual/leakage bounds, and spectral-projection finite-support consequences, including candidate constructive counterexamples.

The proposed Paper 3 ambient-parent-to-retained-reference role is described in [`../../../docs/BandGauge/higher-rank-composite-band-formalization-plan.md`](../../../docs/BandGauge/higher-rank-composite-band-formalization-plan.md). Projection must remain distinct from disentanglement, basis/gauge transformation, Fourier conversion, and truncation. No Lean statement exists in this folder yet.
