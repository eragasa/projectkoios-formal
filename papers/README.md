# Working papers

This directory contains non-authoritative synthesis manuscripts.

- `ragasa-formalization-working-paper.tex` summarizes audited Ragasa2026A--C claim families.
- Exact proof status remains in `docs/theorem-manifest.md`.
- Statement explanations remain in `proofs/`.
- Owner-publication prose remains in the owner repository.

## Requirements

Working papers must preserve every authority boundary.

- Preserve immutable source locators and dirty-state limits.
- Separate analytic claims, contracts, numerical evidence, and nonclaims.
- Link formal results to statement IDs and dossiers.
- Mark incomplete claims, citations, certificates, and instantiations.
- Disclose AI assistance, trusted-base limits, and independent-review status.
- Do not claim novelty for standard mathematics without a separate review.

Compile into a temporary directory. Do not commit generated PDFs, logs, auxiliary files, or bibliography output.
