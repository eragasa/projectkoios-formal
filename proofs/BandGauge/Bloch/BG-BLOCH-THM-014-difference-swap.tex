\section{Exact mathematical statement}
Reversing the two operator fields negates their declared difference:
\[
  \operatorname{Diff}(H_{\mathrm{cand}},H_{\mathrm{ref}})
  =-\operatorname{Diff}(H_{\mathrm{ref}},H_{\mathrm{cand}}).
\]

\section{Assumptions and conventions}
Both fields act on the same complex fiber. The definition always places its first argument on
the left, so swapping arguments changes reference-minus-candidate to candidate-minus-reference.

\section{Mathematical argument}
At each point the swapped field is $H_{\mathrm{cand}}-H_{\mathrm{ref}}$. The additive-group
identity $b-a=-(a-b)$ identifies this with the pointwise negation of the original difference.
Function extensionality then lifts the pointwise equality to equality of operator fields.

\section{Lean realization}
The Lean proof applies function extensionality in the point variable and simplifies the unfolded
difference with \texttt{neg\_sub}. It was checked with Lean \texttt{4.35.0} and Mathlib commit
\texttt{56a005855ea17e0b0958f73ec801ae140b0a1679}.
