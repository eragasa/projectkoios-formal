\section{Human-readable proof}
From $|\mu|\le1$, squaring gives $\mu^2\le1$, hence $0\le1-\mu^2$. Multiplication by
$\kappa\ge0$ preserves nonnegativity.

    {κ μ : ℝ} (hκ : 0 ≤ κ) (hμ : |μ| ≤ 1) :
    0 ≤ κ * (1 - μ ^ 2)
