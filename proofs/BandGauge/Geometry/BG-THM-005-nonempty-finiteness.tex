\section{Exact mathematical statement}

Let $X$ be a metric space and let $A,B\subseteq X$ be nonempty. Then
\[
 \delta_{\mathrm e}(A,B)\ne\infty.
\]

\section{Human-readable proof}

Nonemptiness supplies one point from each set. BG-THM-001 bounds the set distance by the
extended distance between those points. Every extended distance in a metric space is
strictly below infinity. Therefore the set distance is finite.
