\section{Proof}

order-preserving and order-reflecting. BG-THM-015 replaces the square of the real loss by
the reduced squared-loss formula.
\begin{lstlisting}
theorem rankTwoSpectralLoss_le_iff_sq_le_sq
    {κ spectralBudget : ℝ} (hκ : 0 ≤ κ)
    (hBudget : 0 ≤ spectralBudget) (p : RankTwoParameter) :
    rankTwoSpectralLoss κ p ≤ spectralBudget ↔
