\section{Exact statement}
For nonnegative radii, the real admissible-set distance between the two closed balls is
\[
 \operatorname{dist}(B(c_1,r_1),B(c_2,r_2))
 =\max\{0,d(c_1,c_2)-r_1-r_2\}.
\]
The real distance is the proof-gated conversion of the repository's extended
nonnegative set distance.

\section{Proof}
BG-HILBERT-THM-002 bounds every pairwise distance below by the closed formula, so it
bounds the set infimum. BG-HILBERT-THM-003 supplies a pair attaining the same formula,
which gives the reverse bound. Nonnegative radii make both balls nonempty, permitting
the exact conversion from extended to real distance.
